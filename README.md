# CBR Server — Королевская Битва онлайн

## Установка и запуск

```bash
npm install
node server.js
```

Сервер запустится на http://localhost:3000

## Деплой на Railway (бесплатно)

1. Зарегистрируйся на https://railway.app
2. New Project → Deploy from GitHub repo
3. Загрузи эту папку в GitHub
4. Railway автоматически запустит `node server.js`
5. Получишь URL вида `your-app.railway.app`

## Архитектура (Этап 1)

Сервер обрабатывает:
- `room:create` — создать комнату, получить код
- `room:join` — войти по коду
- `room:ready` — игрок готов к старту
- `game:move` — отправить свой ход
- `room:rejoin` — реконнект после обрыва

Клиент получает:
- `room:update` — список игроков в лобби
- `game:start` — игра началась, список игроков с id/цветами
- `game:player_moved` — кто-то выбрал ход
- `game:all_ready` — все выбрали, можно исполнять раунд
- `game:state` — текущее состояние (при реконнекте)

## Следующие этапы

- **Этап 2:** Лобби UI в игре (создать/войти по коду)
- **Этап 3:** Синхронизация хода через сервер
- **Этап 4:** Перенос логики раунда на сервер
- **Этап 5:** Реконнект и обработка отключений
